# 🤟 FABLIBRAS

## 📚 Plataforma de Ensino de LIBRAS

O FABLIBRAS é um projeto desenvolvido com o objetivo de promover inclusão, acessibilidade e equidade através do ensino gratuito da Língua Brasileira de Sinais (LIBRAS).

A plataforma busca conectar pessoas por meio da educação e da tecnologia, oferecendo conteúdos acessíveis, interativos e gratuitos para ampliar a comunicação entre pessoas surdas e ouvintes.

---

## 🌍 Objetivo do Projeto

Promover inclusão social utilizando tecnologia e educação como ferramentas de transformação, tornando o aprendizado de LIBRAS mais acessível para todos.

---

## ✨ Funcionalidades

- 📖 Cursos gratuitos de LIBRAS
- 🎥 Videoaulas e conteúdos interativos
- 📱 Plataforma responsiva
- 🌐 Acesso online de qualquer lugar
- ♿ Foco em acessibilidade e inclusão
- 🚀 Interface moderna e intuitiva

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bubble.io
- Git & GitHub

---

## ♿ Acessibilidade

O projeto busca seguir princípios de acessibilidade digital e inclusão social, utilizando traduçao em LIBRAS.
